The NPV Calculation

First, because this is a pirates game, we used pirates' lingo for the NPV's variables so that it would look like this:

  • Cash Flows (CFs) = Booty
  • Initial cost of the project = Blood
  • t = Plunders

Plunders corresponds to the number of years, which is also the number of turns the player has.

In our NPV calculation, at the start of every game:

  • We select the CFs value at random from 1 to 10, which we maintain throughout the years.
  • We select at random a value from 0.2 to 0.7 for the r-value location of the pirate and player. We used 0.2 and 0.7 due to the weapons' locations and the ease of the game.
  • We compute the value of the Initial Cost that will make the NPV equal to zero using either the pirate's r location for the player or the player's r location for the pirate because we need their locations' r value to be the IRR for the NPV equation. Once we have the Initial Cost, we can solve the NPV equation.

Since the NPV equation looks like this:
\[ \boldsymbol{ \text{NPV} = \frac{\text{CFs}}{r}\left(1 - (1 + r)^{-t}\right) - \text{Initial Cost} } \]

Then, we will solve for Blood:
\[ \text{Initial Cost} = \frac{\text{CF}}{r}\left(1 - (1 + r)^{-t}\right) - \text{NPV} \]
\[ \text{Initial Cost} = \frac{\text{CF}}{r}\left(1 - (1 + r)^{-t}\right) - 0 \]
\[ \text{Initial Cost} = \frac{\text{CF}}{r}\left(1 - (1 + r)^{-t}\right) \]

Now that we have all of the variables, we can solve for the NPV.

The Physics

The Shooting Arc

Both the Cannon and the Blunderbuss use the same projectile motion physics to determine the path of a shot. Given a launch angle \( \theta \) and a shot speed v (the power), we plot the trajectory of each bullet.

Assumptions:

  • No air resistance - vacuum.
  • No spin.
  • No bullet size. We treat the bullet as a single point.

Before we dive into the calculations, we need to make sure we understand the basics of physics.
Let us define the variables:

  • \( \vec{F} \) = Force
  • \( \vec{a} \) = Acceleration
  • \( \vec{v} \) = Velocity (Power)
  • \( \vec{g} \) = Gravity (9.81)
  • m = Mass
  • \( \theta \) = Launch angle

According to Newton's 2nd Law:
\[ \vec{F} = m\vec{a} \]
Since we are assuming we are in a vacuum:
\[ m\vec{g} = m\vec{a} \]
Therefore:
\[ \vec{g} = \vec{a} \]
That means that the only force that acts down on the bullet is gravity's acceleration, so we do not need to assign masses to each bullet.

Another important point to note is that an object experiences acceleration only when a force is acting upon it.

After understanding the basics, we can start solving for the horizontal and vertical movement, x and y, of the bullet.

Let us start with the x-axis:
Since velocity is the derivative of position
\[ \vec{v_x} = \frac{dx}{dt} \]
Since \( \vec{v_x} \) is a constant:
\[ \frac{dx}{dt} = v\cos{\theta} \]
Then, we integrate with respect to t:
\[ \int dx = \int v\cos{\theta}\, dt \]
Since
\[ \int dx = x \]
And
\[ \int v\cos{\theta}\,dt = v\cos{\theta}\,t \]
Therefore, the equation for finding the location of the bullet on the x-axis is:
\[ \boxed{ \boldsymbol{ x(t) = v\cos(\theta)\,t } } \]


Now, let us take a look at the y-axis:
Now that we have the force of gravity acting upon the bullet
\[ \vec{v_y} = -g \]
Since
\[ v = \frac{dy}{dt} \]
\[ \vec{a} = \frac{d^2y}{dt^2} \]
So
\[ \vec{a_y} = \frac{dv_y}{dt} \]
\[ -\vec{g} = \frac{dv_y}{dt} \]
\[ dv_y = -g\cdot dt \]
From here, we integrate acceleration with respect to t
Since
\[ \int dv_y = v_y \]
And
\[ \int -g\cdot dt = -gt + C \]
Because we are integrating acceleration to get velocity, so at t=0:
\[ v_y(0) = -g\cdot 0 + C \]
\[ v_y(0) = C \]
Therefore
\[ v_y(t) = -g + v_y(0) \]
Because it is angle-dependent, we have:
\[ v_y(0) = v\sin(\theta) \]
\[ v_y(t) = -gt + v\sin(\theta) \]
Now, let us integrate velocity
\[ v_y = \frac{dy}{dt} \]
\[ \frac{dy}{dt} = -gt + v\sin(\theta) \]
\[ \int dy = \int -gt\cdot dt + \int v\sin(\theta)dt \]
\[ y(t) = v\sin{\theta}\,t - \tfrac{1}{2}gt^2 + C \]
Again, at t = 0, C = 0:
\[ \boxed{ \boldsymbol{ y(t) = v\sin(\theta)\,t - \tfrac{1}{2}gt^2 } } \]

Finding Theta (\( \theta \))

As the pirate is not a real player, but yet has to make a shot, we need to calculate the angle that he needs to shoot at in order for him to hit the r-value that he "selected".

Variables:

  • \( x_0, y_0 = \text{The starting position of the pirate's weapon} \)
  • \( x_1, y_1 = \text{The position of the pirate's shot on the ground - the target} \)
  • t = Here, it is the time it takes to hit the target and not the time step

Because the pirate is shooting from left to right:
\( x_1 = x_0 + v\cos{\theta}\,t \)
\( y_1 = y_0 - (v\sin{\theta}\,t - \tfrac{1}{2}gt^2) \)
We are subtracting \( y_0 \) from the rest of the equation because, in the game, to go up, we need to subtract from the total screen size.

Before we can find Theta (\( \theta \)), we need to find t, so let us start by solving for t:
\[ x_1 - x_0 = v\cos{\theta}\,t \]
Let
\[ dx = x_1 - x_0 \]
\[ dx = v\cos{\theta}\,t \]
\[ t = \frac{dx}{v\cos{\theta}} \]

Now that we know t, let us use it to help us find \( \theta \)
\[ y_1 - y_0 = -v\sin{\theta}\,t + \tfrac{1}{2}\,gt^2 \]
Let
\[ dy = y_1 - y_0 \]
\[ dy = -v\sin{\theta}\,t + \tfrac{1}{2}\,gt^2 \]
Substituting the value of t
\[ dy = -v\sin{\theta}\frac{dx}{v\cos{\theta}} + \tfrac{1}{2}g(\frac{dx}{v\cos^{2}(\theta)}) \]
\[ dy = -\sin{\theta}\frac{dx}{\cos{\theta}} + \tfrac{1}{2}\,g(\frac{dx}{v\cos^{2}(\theta)}) \]
\[ dy = -dx\frac{\sin{\theta}}{\cos{\theta}} + \tfrac{1}{2}\,g(\frac{dx^2}{v^2\cos^{2}(\theta)}) \]
Since:
\[ \frac{\sin{\theta}}{\cos{\theta}} = \tan{\theta} \qquad ; \qquad \frac{1}{\cos^{2}(\theta)} = 1 + \tan^{2}(\theta) \]
Then:
\[ dy = -dx\cdot \tan{\theta} + \frac{g\cdot dx^2}{2v^2}\,(1 + \tan^{2}(\theta)) \]
Let
\[ T = \tan{\theta} \qquad ; \qquad K = \frac{g\cdot dx^2}{2v^2} \]
Keep in mind that K is just a constant
\[ dy = -dx\cdot T + K(1 + T^2) \]
\[ dy = -dx\cdot T + K + T^2\cdot K \]
\[ dy = K\cdot T^2 - dx\cdot T + K \]
Let \( dy = 0 \) and solve the qudratic equation
\[ K\cdot T^2 - dx\cdot T + K = 0 \]
Using the quadratic formula:
\[ ax^2 + bx + c = 0 \]
\[ x = \frac{-b \pm\sqrt{b^2 - 4ac}}{2a} \]
Then:
\[ T = \frac{-(-dx) \pm\sqrt{(-dx)^2 - 4\cdot K\cdot (K - dy)}}{2K} \]
\[ \boxed{ \boldsymbol{ \theta = \tan^{-1}(T) } } \]
By computing this, we will receive two solutions for \( \theta \), but we will only use the smallest \( \theta \).

Rotating The Axes

When we take an object's x and y coordinates, it outputs its position relative to the center of the object. However, because we want the bullet and the arc to exist from the tip of the barrel, we have to find the tip of the barrel at every angle. To find the tip of the barrel coordinates at every level, we needed to rotate the axis.

Our first step was to find the coordinates when the angle was zero.
The next step is to understand that every \( (x , y) \) coordinate is equal to \( x(1 , 0) + y(0 , 1) \), so:
\[ (x , y) = x(1 , 0) + y(0 , 1) \]
Let
\[ i = (1 , 0) \qquad ; \qquad j = (0 , 1) \]
But because we are shooting from right to left, we will apply a vertical reflection on the x-axis:
\[ i = (-1 , 0) \]
Then, we will use i' and j' to represent the unit vectors. Where j' is perpendicular to i'. Therefore, j' is the derivative of i' with respect to \( \theta \).
Since
\[ \frac{d}{dx}\sin{\theta} = \cos{\theta} \]
\[ \frac{d}{dx}\cos{\theta} = -\sin{\theta} \]
Then
\[ i' = (\cos{\theta} , \sin{\theta}) \]
\[ j' = (-\sin{\theta} , \cos{\theta}) \]
So the 2D matrix is:
\[ \mathbf{i}' = \begin{pmatrix} \cos\theta \\ \sin\theta \end{pmatrix} \qquad ; \qquad \mathbf{j}' = \begin{pmatrix} -\sin\theta \\ \cos\theta \end{pmatrix} \]
\[ R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \] Then that means:
\[ \boxed{ \boldsymbol{ x' = x\cdot \cos{\theta} + y\cdot (-\sin{\theta}) = x\cos{\theta} - y\sin{\theta} } } \]
\[ \boxed{ \boldsymbol{ y' = x\sin{\theta} + y\cos{\theta} } } \]

Levels of Difficulty

Easy Level - Bisection Method

The Bisection method is calculated by starting with an interval range that is between the numbers 0 and 1, such as \([0, 0.5]\), for example. From there, we will compute the midpoint or the average number for those two values, which will look like this:

\( \text{midpoint} = \frac{0 + 0.5}{2} \)

Once we obtain the midpoint, we use it as the pirate's r guess value for the NPV calculation, so we perform \(NPV(0.25)\).
- If it comes out that the NPV is positive, we know that the midpoint is too low and we will set it as the pirate's lower limit: \([0.25,0.5]\)
- If it comes out that the NPV is negative, we know that the midpoint is too high, and we will set it as the pirate's higher limit: \([0,0.25]\)

The goal is to achieve an NPV of zero, as the IRR sets our NPV to zero; this is how we will determine the IRR.

Medium Level - Newton-Raphson Method

The Newton-Raphson method is calculated by starting with a random r value, which we made to be between 0.2 and 0.7. From there, we will need to calculate the derivative of the NPV and determine the slope at the r-value that the player selected. Once we find the slope, we can also calculate the NPV value at the chosen r-value.

The first step is to calculate the derivative of the NPV function with respect to r
\[ \text{NPV} = \frac{\text{CFs}}{r}\left(1 - (1 + r)^{-t}\right) - \text{Initial Cost} \]
\[ \frac{d}{dr} \text{NPV} = \frac{\text{CFs}}{r}\left(1 - (1 + r)^{-t}\right) - \text{Initial Cost} \]
Let
\[ f(r) = 1 - (1 + r)^{-t} \]
Since
\[ \frac{d}{dr} f(h(r)) = f'(h(r)) \cdot h'(r) \]
Then
\[ \frac{d}{dr} f(r) = 0 - (-t) \cdot (1 + r)^{-t - 1} \cdot 1 \]
\[ \frac{d}{dr} f(r) = t \cdot (1 + r)^{-(t + 1)} \]
Also, since
\[ \frac{d}{dr} f(r) \cdot h(r) = g(r) \cdot f'(r) + f(r) \cdot g'(r) \]
Then
\[ \frac{d}{dr} \text{NPV} = \text{CFs} \cdot r^{-1} \cdot (1 - (1 + r)^{-t}) - \text{Initial Cost} \]
\[ \frac{d}{dr} \text{NPV} = (1 - (1 + r)^{-t}) \cdot \text{CFs} \cdot (-r)^{-2} + \text{CFs} \cdot r^{-1} \cdot t \cdot (1 + r)^{-(t + 1)} - 0 \]
\[ \frac{d}{dr} \text{NPV} = \frac{\text{CFs}}{r} \cdot t \cdot (1 + r)^{-(t + 1)} - \frac{\text{CFs}}{r^{2}} \cdot (1 - (1 + r)^{-t}) \]
Therefore
\[ \boxed{ \boldsymbol{ \text{NPV'} = \frac{\text{CFs}}{r} \cdot t \cdot (1 + r)^{-(t + 1)} - \frac{\text{CFs}}{r^{2}} \cdot (1 - (1 + r)^{-t}) } } \]
Or, since the numerical derivative has a higher accuracy, we can calculate NPV' this way
By definition
\[ f'(r) = \frac{(f(r + h) - f(r - h))}{2h} \]
Where
h = a very small step size, which we will set to be \( 1 \cdot 10^{-5} \)

We will make new variables for forward and backward \( r \) (\( r_f \) and \( r_b \)) and limit them to our domain to avoid division by zero:

  • \( r_f = \text{min}(1.0, r + h) \)
  • \( r_b = \text{max}(1 \cdot 10^{-8}, r - h) \)

However, when \( r \) is near the boundaries, dividing by \( 2h \) may not be accurate because \( 2h \) is derived from
\[ (r + h) - (r - h) \]
\[ r + h -r + h \]
\[ 2h \]
When \( r \) is near the boundaries
\[ r_f = 1.0 \]
\[ r_b = 0.999989 \]
So
\[ r_f - r_b \]
\[ 1.0 - 0.999989 = 1.1 \cdot 10^{-5} \]
Which is not \( 2h \), so we revert to
\[ (r + h) - (r - h) \]
Which is
\[ r_f - r_b \]
Therefore
\[ \boxed{ \boldsymbol{ f'(r) = \frac{f(r_f) - f(r_b)}{r_f - r_b} } } \]
Now that we know how to find \( NPV' \), we can proceed forward and use the linear approximation equation to approximate the function of the IRR, allowing us to find its value.

The linear approximation equation is
\[ y = \text{NPV}(r) + \text{NPV’}(r) * (x - r) \]
Then, we let \( y = 0 \) so we can isolate for x, which is the IRR value we are approximating.
\[ 0 = \text{NPV}(r) + \text{NPV’}(r) * (x - r) \]
\[ x = r - \frac{\text{NPV}(r)}{\text{NPV'}(r)} \]
The result for x, as mentioned above, is the approximation for IRR that the Pirate will use during its turn.

However, we want to control how aggressively the pirate guesses the r-value of the player. Therefore, we will use alpha, \( \alpha \), to do that.
\[ \boxed{ \boldsymbol{ x = r - \alpha \cdot \frac{\text{NPV}(r)}{\text{NPV'}(r)} } } \]
